Validations needed:

- Ignore includes for now!

- verify i/o datatypes. Only a few valid options:
    - none
    - boolean
    - number
    - string
    - number_array
    - string_array
    - color
    - sound
    - image
    - any
- Should sum types be allowed? e.g. `string|number`... Not for now.

- Each i/o datatype can only have specific constraints.
    - none
        - cannot have ANY constraints
    - boolean
        - cannot have ANY constraints
    - number
        - integer or float
        - min (inclusive)
        - max (inclusive)
        - decoration (time fmt, num decimals, etc)
    - string
        - no constraints other than type?
    - number_array
        - no constraints other than type?
    - string_array
        - no constraints other than type?
    - color
        - no constraints other than type-inherent.
    - sound
        - no constraints
    - image
        - no constraints
    - any
        - no constraints


- inputs/outputs cannot have the same name!

- only `!tick` and `!init` events are supported currently.

- tags:
    - if tag has a parent, the parent tag must exist!
    - no circular parent routes! e.g. `@1 in @2 ... @2 in @1` is not allowed.
